# 블루문 — 화면 설계 스토리보드

- **프로젝트**: RAG 인사이트 기반 모의투자 포트폴리오 트래커
- **프론트엔드**: Next.js (완료, mock 데이터 기반)
- **백엔드**: Spring Boot (설계 예정)
- **AI 인사이트**: Python RAG 마이크로서비스 (설계 예정)
- **문서 목적**: 화면별 요구사항을 명확히 정의해서, 이 문서를 기준으로 Spring Boot API를 설계한다.

---

## 1. 전체 화면 흐름

대시보드가 진입점이며, 좌측 사이드바를 통해 5개 화면 어디서든 다른 화면으로 이동할 수 있다.
종목 상세에서는 매수/매도 버튼으로 해당 종목이 미리 선택된 채 매수/매도 화면으로 직접 진입한다.

| 화면 | 경로 | 진입 방법 |
|---|---|---|
| 대시보드 | `/dashboard` | 앱 진입 시 기본 |
| 종목 상세 | `/stocks/{code}` | 사이드바, 보유종목 표 클릭, 대시보드 표 클릭 |
| 매수/매도 | `/trade?code=&side=` | 사이드바, 종목상세 매수/매도 버튼 |
| 거래 내역 | `/history` | 사이드바 |
| 보유 종목 | `/holdings` | 사이드바 |

## 2. 화면별 상세 명세

### 2.1 대시보드 (`/dashboard`)

**사용자 목표**: 로그인 직후 전체 자산 현황을 한눈에 파악하고, 오늘의 AI 추천 종목을 확인한다.

**레이아웃 구성**
- 상단: 총 평가금액 / 총 손익 / 투자 원금 요약 카드 3개
- 좌: 자산 변화 추이 라인 차트 (기간 선택 가능)
- 우: AI 인사이트 카드 (오늘의 추천 종목 1개 + 근거 + 출처)
- 하단 좌: 보유 종목 요약 표 (종목/현재가/손익/수익률)
- 하단 우: 자산 배분 도넛 차트

**사용자 인터랙션**
- 기간 변경 드롭다운 → 차트 데이터 재조회
- 보유 종목 표 행 클릭 → 종목 상세로 이동
- AI 인사이트 카드의 종목명 클릭 → 해당 종목 상세로 이동

**필요 데이터 / API (제안)**
| 엔드포인트 | 메서드 | 용도 |
|---|---|---|
| `/api/portfolio/summary` | GET | 총 평가금액, 총 손익, 원금 |
| `/api/portfolio/trend?period=` | GET | 자산 변화 추이 차트 |
| `/api/holdings` | GET | 보유 종목 요약 표, 자산 배분 차트 |
| `/api/insights/today` | GET | AI 추천 종목 1개 + 근거 + 출처 (Python RAG 서비스 프록시) |

**상태 처리**
- 로딩: 요약 카드 3개 + 차트 영역 스켈레톤
- 빈 상태: 보유 종목이 0개면 "아직 보유한 종목이 없습니다 → 매수하러 가기" 안내
- 에러: AI 인사이트 조회 실패 시에도 나머지 화면은 정상 표시하고, 인사이트 카드만 "일시적으로 인사이트를 불러올 수 없습니다"로 대체 (RAG 서비스 장애가 전체 대시보드를 막지 않도록)

**관련 컴포넌트**: `AiInsightCard`, `HoldingsTable(variant=compact)`, `AssetTrendChart`, `AllocationChart`

---

### 2.2 종목 상세 (`/stocks/{code}`)

**사용자 목표**: 특정 종목의 시세 추이, 내 매매 이력, AI 뉴스 인사이트를 확인하고 매수/매도로 진입한다.

**레이아웃 구성**
- 상단: 종목 선택 칩 (보유 종목 리스트)
- 헤더: 종목명/코드, 현재가, 등락, 매수/매도 버튼
- 좌: 30일 시세 추이 차트
- 우: AI 인사이트 카드 (해당 종목 뉴스/공시 요약)
- 하단: 내 매매 이력 표 (이 종목만)

**사용자 인터랙션**
- 상단 칩 클릭 → 다른 종목으로 전환 (라우트 이동)
- 매수/매도 버튼 → 해당 종목이 선택된 채 매수/매도 화면으로 이동

**필요 데이터 / API (제안)**
| 엔드포인트 | 메서드 | 용도 |
|---|---|---|
| `/api/stocks/{code}` | GET | 종목명, 현재가, 전일종가 |
| `/api/stocks/{code}/price-history?days=30` | GET | 시세 추이 차트 |
| `/api/trades/{code}` | GET | 내 매매 이력 (이 종목만) |
| `/api/insights/{code}` | GET | AI 뉴스 인사이트 (Python RAG 서비스 프록시) |

**상태 처리**
- 로딩: 차트/인사이트/표 각각 개별 스켈레톤 (전체 페이지 블로킹 금지)
- 빈 상태: 매매 이력 없으면 "아직 이 종목의 매매 기록이 없습니다"
- 에러: 존재하지 않는 종목 코드 접근 시 404 페이지

**관련 컴포넌트**: `StockPicker`, `PriceChart`, `AiInsightCard`

---

### 2.3 매수 / 매도 (`/trade`)

**사용자 목표**: 종목/수량/주문방식을 정해 모의 주문을 체결한다.

**레이아웃 구성**
- 좌: 매수/매도 탭, 종목 선택, 주문방식(시장가/지정가), 수량 입력, 예상 체결금액, 주문 버튼
- 우: 선택 종목의 현재가/보유수량/평단가 요약

**사용자 인터랙션**
- 매수/매도 탭 전환
- 시장가 ↔ 지정가 전환 (지정가 선택 시 가격 입력란 노출)
- 수량/가격 입력 시 예상 체결금액 실시간 계산
- 주문하기 → 확인 모달 → 확인 시 주문 접수

**필요 데이터 / API (제안)**
| 엔드포인트 | 메서드 | 용도 |
|---|---|---|
| `/api/stocks` | GET | 종목 선택 드롭다운 |
| `/api/stocks/{code}` | GET | 선택 종목 현재가/보유정보 |
| `/api/orders` | POST | 주문 생성 (매수/매도, 시장가/지정가, 수량) |

**상태 처리**
- 유효성 검사: 수량 0 이하, 지정가 미입력, 매도 시 보유수량 초과 → 인라인 에러 표시 후 주문 버튼 비활성화
- 주문 처리 중: 버튼 로딩 스피너, 중복 클릭 방지
- 에러: 주문 실패 시(잔고 부족 등) 모달에 실패 사유 표시, 화면은 유지

**관련 컴포넌트**: `TradeForm`, `ConfirmModal`

**참고**: 앞서 논의한 동시성 이슈(같은 종목을 여러 요청이 동시에 매도하는 경우)는 이 화면의 `POST /api/orders` 처리 로직에서 백엔드가 책임진다 (재고 관리와 동일 패턴).

---

### 2.4 거래 내역 (`/history`)

**사용자 목표**: 전체 매매 기록을 종목별로 조회한다.

**레이아웃 구성**
- 상단: 종목 필터 드롭다운
- 표: 일시 / 종목 / 구분(매수·매도) / 수량 / 체결가 / 금액

**사용자 인터랙션**
- 종목 필터 변경 → 표 재조회

**필요 데이터 / API (제안)**
| 엔드포인트 | 메서드 | 용도 |
|---|---|---|
| `/api/orders?code=&page=&size=` | GET | 거래 내역 조회 (필터, 페이지네이션) |

**상태 처리**
- 빈 상태: "거래 내역이 없습니다" (이미 프론트에 구현되어 있음)
- 대량 데이터 대비: 페이지네이션 또는 무한 스크롤 (현재 mock은 전체 로드, 실 서비스 전환 시 페이지네이션 필요)

**관련 컴포넌트**: `HistoryTable`

---

### 2.5 보유 종목 (`/holdings`)

**사용자 목표**: 보유 중인 모든 종목의 평단가 대비 손익을 확인한다.

**레이아웃 구성**
- 표: 종목 / 보유수량 / 평단가 / 현재가 / 평가금액 / 평가손익 / 수익률

**사용자 인터랙션**
- 행 클릭 → 종목 상세로 이동

**필요 데이터 / API (제안)**
| 엔드포인트 | 메서드 | 용도 |
|---|---|---|
| `/api/holdings` | GET | 보유 종목 전체 (대시보드와 동일 엔드포인트 재사용) |

**상태 처리**
- 빈 상태: "보유한 종목이 없습니다 → 매수하러 가기"

**관련 컴포넌트**: `HoldingsTable(variant=full)`

## 3. 공통 UI 요소

### 사이드바
- 5개 메뉴, 현재 경로에 따라 활성 상태 표시
- 모바일(880px 이하)에서는 상단 가로 스크롤 형태로 전환

### 티커 테이프 (전 화면 상단 고정)
- 보유 종목의 현재가/등락을 무한 스크롤로 표시
- 국내 관행에 따라 상승=빨강, 하락=파랑

### AI 인사이트 카드
- 앰버색으로 시각적 구분, 출처 태그 필수 표기
- 하단에 "투자 판단과 책임은 본인에게 있습니다" 면책 문구 고정 (법적 검토 사항, 3장 참고)

### 확인 모달
- 매수/매도 주문 최종 확인 시에만 사용
- 종목/구분/주문방식/수량/예상금액 요약 후 확인·취소

|---|---|---|
| `/api/portfolio/summary` | GET | 대시보드 |
| `/api/portfolio/trend` | GET | 대시보드 |
| `/api/holdings` | GET | 대시보드, 보유종목 |
| `/api/stocks/{code}` | GET | 종목상세, 매수매도 |
